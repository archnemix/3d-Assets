## What CC0 does not cover

- An author's stated request is honoured even where CC0 would legally allow more. A source whose creator asks that copies not be redistributed or resold is not accepted, and any already-published asset from such a source is retired. KayKit was withdrawn on exactly this basis.
- CC0 waives copyright and related rights. It does not waive trademark or patent rights, and it does not clear rights a third party may hold in a depicted subject.
- CC0 offers no warranty. The library's own technical and visual checks are the quality guarantee, not the license.
- Nothing here is exclusive. The same files are available to everyone else under the same terms.
- A provider can change future terms, but a CC0 dedication already applied to a published work is irrevocable. Every asset folder keeps the license text and evidence URL that applied at acquisition time.
- Storefronts have their own submission rules. AI-assisted assets may need a content disclosure (for example on Steam) even though the license permits the use.

## Source terms and caveats

### Grab3D — `grab3d`

3 approved assets. Status: **verified**.

- Terms: <https://grab3d.com/license/>
- Pinned evidence: <https://grab3d.com/license/>
- Reselling the files themselves: The license page explicitly allows redistributing the models, original or modified, and explicitly allows reselling the models themselves.

- Every download package ships its own LICENSE.txt and manifest.json, and the adapter verifies both before fetching the model. No attribution, account or fee is required, and the license file does not have to ship with your product.
- Grab3D waives only its own rights. Subjects are described as generic, with no brands, logos or real people.
- The Grab3D name may not be used to imply endorsement.
- Models generally start as an AI image-to-3D draft that is then cleaned up, scaled, textured and checked in Blender; rigged packages add an auto-generated skeleton and clips. This is recorded per asset as origin.ai_content and the ai-assisted tag.

### Kenney — `kenney`

10 approved assets. Status: **verified**.

- Terms: <https://kenney.nl/support>
- Pinned evidence: <https://raw.githubusercontent.com/Hidencod/tge-assets/d92c6e923bbef8649d4e5be3ab375a40f88672b0/LICENSE>
- Reselling the files themselves: The CC0 dedication places no restriction on resale. Kenney asks for nothing beyond the license, but repackaging a free pack as a paid product is a poor way to treat a creator who released it for free.

- The standalone page https://kenney.nl/license returned 404 when checked on 2026-11-04. The evidence used instead is the support page (all asset-page assets are CC0, attribution not required) plus the license file pinned in the exact source revision each asset came from.
- Kenney reserves its studio logo for official projects. The logo is not part of any asset here and must not be used to imply endorsement.
- Files come from a pinned third-party mirror that converts Kenney's packs to GLB. That mirror's license explicitly releases its conversions, embedded textures and thumbnails under CC0 as well. Kenney remains the original creator and is recorded as such.

### Poly Haven — `polyhaven`

14 approved assets. Status: **verified**.

- Terms: <https://polyhaven.com/license>
- Pinned evidence: <https://raw.githubusercontent.com/Poly-Haven/Public-API/2fd1796dc3506dfa8269439aac8e6f5c65876bd1/ToS.md>
- Reselling the files themselves: The license page states the assets can be redistributed, including inside a product you sell.

- Only the assets are CC0. Site content such as the Poly Haven logo, staff avatars, example renders and page text stays protected, so this library renders its own previews instead of copying promotional imagery.
- Using the live discovery API is covered by separate API terms. They ask for a visible 'Powered by Poly Haven' service credit in software that calls the API. The same terms state explicitly that downloaded or self-hosted CC0 assets carry no attribution requirement whatsoever; this gallery serves local files and keeps the credit as a courtesy.
- A few Poly Haven assets carry a trademark warning flag in their API metadata. None of the approved assets in this library carry that flag; each asset stores the API metadata it was selected from.
